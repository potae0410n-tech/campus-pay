# คำอธิบายโมดูลการทำงานของโปรแกรม (Program Structure Description)

1. **โมดูลการยืนยันตัวตน (Authentication Module):**
   - `loginUser` ตรวจสอบรหัสนักศึกษาหรือชื่อผู้ใช้และรหัสผ่านกับฐานข้อมูล (User) โดยเทียบรหัสผ่านที่เข้ารหัสแบบ Bcrypt
   - `registerUser` ลงทะเบียนสมาชิกใหม่ ตรวจสอบชื่อผู้ใช้และรหัสนักศึกษาไม่ให้ซ้ำ เข้ารหัสรหัสผ่าน และกำหนดสิทธิ์เริ่มต้นเป็นนักศึกษา (STUDENT)
   - `requireUser` ตรวจสอบว่าผู้ใช้เข้าสู่ระบบแล้วก่อนเข้าถึงหน้าต่าง ๆ ของระบบ
   - `requireAdmin` แยกสิทธิ์การเข้าใช้งานระหว่างนักศึกษา (Student) และเหรัญญิก (Admin) โดยอนุญาตเฉพาะเหรัญญิกเข้าหน้าผู้ดูแล
   - `logoutUser` ยกเลิก Session การเข้าสู่ระบบ

2. **โมดูลจัดการเซสชัน (Session Management Module):**
   - `signSession` สร้างและลงลายมือชื่อโทเค็นเซสชันจากรหัสผู้ใช้และบทบาท
   - `verifySession` ตรวจสอบความถูกต้องและวันหมดอายุของโทเค็นเซสชัน (อายุ 7 วัน)
   - `setSessionCookie` บันทึกโทเค็นเซสชันลงคุกกี้ campuspay_session หลังเข้าสู่ระบบสำเร็จ
   - `getSession` อ่านข้อมูลเซสชันของผู้ใช้ปัจจุบันจากคุกกี้
   - `clearSessionCookie` ลบคุกกี้เซสชันเมื่อออกจากระบบ
   - `proxy` (Middleware) ตรวจสอบเซสชันทุกครั้งที่เรียกหน้าเว็บ และเปลี่ยนเส้นทางผู้ใช้ไปยังหน้าที่ตรงกับสิทธิ์

3. **โมดูลจัดการประกาศเรียกเก็บเงิน (Announcement Management Module):**
   - `createAnnouncement` ฟังก์ชันสำหรับเหรัญญิกในการสร้างประกาศเรียกเก็บเงินใหม่ พร้อมกำหนดจำนวนเงิน บัญชีธนาคาร วันเริ่มชำระ และวันครบกำหนด แล้วสร้างรายการชำระเงิน (UNPAID) ให้นักศึกษาทุกคนอัตโนมัติ
   - `updateAnnouncementQr` อัปโหลดและแก้ไขภาพ QR Code พร้อมเพย์ของประกาศ
   - `getAnnouncements` ดึงรายการประกาศทั้งหมดมาแสดงในหน้าผู้ดูแล
   - `getAnnouncementById` ดึงรายละเอียดประกาศและรายชื่อการชำระเงินของประกาศนั้น
   - `getMyAnnouncements` ดึงรายการประกาศของนักศึกษาที่เข้าสู่ระบบมาแสดงผลให้เลือกชำระเงิน

4. **โมดูลประมวลผลการชำระเงิน (Payment Processing Module):**
   - `uploadSlip` ตรวจสอบไฟล์ภาพสลิป อัปโหลดเข้าสู่เซิร์ฟเวอร์ (UploadThing) และบันทึกข้อมูลลงตาราง Payment พร้อมเปลี่ยนสถานะเป็น PENDING
   - `reviewPayment` ฟังก์ชันสำหรับเหรัญญิกอนุมัติ (APPROVED) หรือปฏิเสธ (REJECTED) สลิปโอนเงิน พร้อมระบุเหตุผลกรณีปฏิเสธ
   - `getMyPaymentHistory` แสดงประวัติและสถานะการชำระเงินของนักศึกษาที่เข้าสู่ระบบ
   - `getAllPaymentHistory` แสดงประวัติการชำระเงินทั้งหมดของทุกคนในหน้าผู้ดูแล

5. **โมดูลออกรายงานและแสดงผลแผงควบคุม (Reporting & Dashboard Module):**
   - `getAdminDashboardStats` ประมวลผลคำนวณยอดรวมรายรับ จำนวนสมาชิกที่ชำระเงินแล้ว สมาชิกที่ค้างชำระ สลิปที่รอตรวจสอบ และเงินกองกลางคงเหลือ
   - `updateGeneralFund` ปรับปรุงยอดเงินกองกลางและเงินรุ่นคงเหลือในตาราง GeneralFund พร้อมบันทึกชื่อผู้ปรับปรุงและวันเวลา

6. **โมดูลจัดการห้องกิจกรรม (Room Management Module):**
   - `createRoom` ฟังก์ชันสำหรับเหรัญญิกสร้างห้องกิจกรรม กำหนดชื่อห้อง ยอดเงิน จำนวนสมาชิกสูงสุด และรหัสผ่านเข้าห้อง
   - `getRooms` ดึงรายการห้องกิจกรรมทั้งหมดมาแสดงผล
   - `getRoomById` ดึงรายละเอียดห้องและรายชื่อสมาชิกในห้อง
   - `joinRoom` ให้นักศึกษาเข้าร่วมห้องกิจกรรมด้วยรหัสผ่านห้อง

7. **โมดูลจัดการไฟล์ (File Upload Module):**
   - `uploadthing core / route` กำหนดชนิดและขนาดไฟล์ภาพที่อนุญาต (สลิปและ QR Code) ตรวจสอบสิทธิ์ผู้อัปโหลด และส่งคืน URL ของไฟล์เพื่อบันทึกลงฐานข้อมูล
